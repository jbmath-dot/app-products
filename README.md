# 앱 제품 소개 사이트

구글 플레이에 올릴 앱을 홍보하는 사이트입니다. Vite + React + Astryx 디자인 시스템으로 만들었습니다.

## 내용 바꾸기

- **글·가격·기능·자주 묻는 질문·개인정보처리방침**: `src/data/apps.ts` 한 파일만 고치면 됩니다. `[채워 주세요]`를 실제 내용으로 바꿉니다.
- **앱 아이콘·화면 캡처**: `public/images/`에 그림 파일을 넣고 `apps.ts`의 `icon`, `screenshots` 경로를 바꿉니다. 화면 캡처는 세로(9:16) 그림이 잘 맞습니다.
- **앱 추가**: `APPS` 목록에 항목을 하나 더 복사해 붙이고 `id`(영문)를 새로 정합니다.
- **출시 후**: `status`를 `'released'`로, `playStoreUrl`에 구글 플레이 주소를 넣으면 "구글 플레이에서 받기" 버튼이 켜집니다.

## 주소 구조

| 화면 | 주소 끝 |
|---|---|
| 첫 화면(앱 목록) | `#/` |
| 앱 소개 | `#/app/<앱 id>` |
| 개인정보처리방침 | `#/privacy/<앱 id>` ← 구글 플레이 콘솔의 "개인정보처리방침 URL"에 입력 |

## 명령

```bash
npm install      # 처음 한 번
npm run dev      # 고치면서 미리 보기
npm run build    # dist/ 폴더에 공개용 파일 생성
```
